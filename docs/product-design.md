# Reminder App 產品設計文檔

## 產品方向

一款輕量的 Windows 桌面提示工具。用戶設定標題、日期和時間，到期後透過鈴聲及 Windows 通知提醒，幫助處理日常待辦事項。

MVP 聚焦「設定容易、準時提醒、減少遺漏」，採用本機儲存，無需註冊帳戶。

## 核心使用流程

1. 安裝時選擇是否在登入 Windows 後自動啟動，預設勾選。
2. 開啟 App，新增提示並填寫標題、日期和時間。
3. 儲存後在列表查看、編輯或刪除提示。
4. 關閉主視窗後，App 繼續在系統匣背景運行。
5. 到期時播放預設鈴聲並顯示 Windows 通知。
6. 用戶可以停止鈴聲、完成提示，或選擇稍後 5 分鐘再提醒。

## MVP 主要功能

| 功能 | 範圍 |
| --- | --- |
| 建立提示 | 必填標題、日期和時間；驗證缺漏及過去時間 |
| 管理提示 | 按到期時間排序，支援查看、編輯、刪除；區分待提醒、已完成及已錯過狀態 |
| 到期提醒 | 同時觸發預設鈴聲及 Windows 通知，提供停止、完成及稍後提醒操作 |
| 本機儲存 | 保存提示及設定，重新啟動後仍可使用 |
| 背景運行 | 關閉視窗後保留系統匣圖示，提供開啟主視窗及明確的退出選項 |
| 錯過提示 | App 重新啟動或電腦喚醒後，補發錯過提示的通知並標記狀態，避免同一提示重複補發 |
| 自動啟動 | 安裝時及 App 設定內皆可控制同一項設定；顯示實際狀態；自動啟動時僅在系統匣運行 |
| 測試提示 | 即時試播鈴聲及顯示通知，方便確認提醒是否正常 |
| 解除安裝 | 移除 App 的自動啟動設定 |

## 介面方向

- **主畫面**：提示列表、狀態、到期時間、新增入口及編輯／刪除操作。
- **新增／編輯提示**：標題、日期、時間和儲存按鈕；以簡短文字顯示輸入錯誤。
- **設定**：登入 Windows 後自動啟動開關及測試提示按鈕。
- **提醒操作**：清楚顯示提示標題，提供停止鈴聲、完成及稍後 5 分鐘提醒。
- **系統匣選單**：開啟 App、進入設定、退出。

整體採用簡潔、易讀的 Windows 桌面介面，讓新增提示及處理到期提醒所需步驟盡量少。

## 運行邊界

- 準時提醒的前提是電腦開機且 App 正在運行；關機、退出 App 或休眠期間不保證即時提醒。
- MVP 不主動喚醒電腦；重新啟動或喚醒後處理已錯過提示。
- 時間以 Windows 本機時間為準，第一版不提供獨立時區選擇。
- Windows 通知顯示可能受系統通知權限及勿擾模式影響，應在測試提示流程中提示用戶檢查。
- 鈴聲播放至用戶停止或達到合理上限；具體上限在實作時確定。

## 暫不納入 MVP

重複提示、自訂鈴聲、帳戶登入、雲端同步、多裝置支援、日曆整合及進階提示分類。

## 驗收方向

- 新增提示後關閉主視窗，到期仍有鈴聲及 Windows 通知。
- 編輯後按新時間提醒；刪除後不再提醒。
- 停止鈴聲可立即生效；完成後不再提醒；稍後提醒會在 5 分鐘後再次觸發。
- 重開 App 後提示及設定保留，錯過提示會補發且不重複補發。
- 安裝時的自動啟動選項與 App 內設定一致；重新登入 Windows 後按設定在背景啟動。
- 停用自動啟動或解除安裝後，不再自動啟動。
- 每次功能改動需編寫或更新相關測試，交付前通過測試及必要的 Windows 實機驗證。
